---
title: Glossary
---
| Term | Meaning |
|---|---|
| **Adduct** | the ion a neutral molecule becomes in the source: [M−H]⁻, [M+H]⁺, [M+Na]⁺… The [[mass-calculator]] lists those supported |
| **Apex** | the highest point of a peak; its time is the retention time reported |
| **Area ratio** | a component's area divided by its internal standard's in the same sample |
| **Baseline** | the signal under a peak that is not the peak; drawn as a straight line between the boundaries at integration, or estimated as a lower envelope by the *Baseline (min)* setting |
| **BPC** | base peak chromatogram: the tallest peak of each scan against time |
| **Carryover** | analyte from one injection appearing in the next; measured in the blank after the top standard — [[detection-limits-and-carryover]] |
| **Centroid** | a profile peak reduced to one stick at its centre of mass |
| **Component** | one target of the method: what to extract, where, and how to report it — [[method-workspace]] |
| **Control chart** | a standard's response against injection order with limits — [[batch-qc]] |
| **%CV** | coefficient of variation: the standard deviation as a percentage of the mean |
| **Da, mDa** | dalton and millidalton; an absolute mass window |
| **Dilution factor** | what a concentration read off the curve is multiplied by to report the original sample |
| **Drift** | a change in response that goes one way across the run |
| **Gaussian fit** | a peak area taken from a bell curve fitted to the points rather than from the trapezoid — [[integration-algorithms]] |
| **Injection response index** | the median over the internal standards of each one's response relative to its own median, per injection — [[batch-qc]] |
| **Internal standard (IS)** | a compound spiked into every sample at one amount, against which analytes are ratioed — [[internal-standards-and-qualifiers]] |
| **Ion ratio** | a qualifier's area as a percentage of its quantifier's |
| **LM_ID** | a LIPID MAPS record identifier, `LMSP03010003` — [[lipid-maps]] |
| **LOD, LOQ** | limits of detection and quantitation, 3.3σ/S and 10σ/S — [[detection-limits-and-carryover]] |
| **MAD** | median absolute deviation: a spread an outlier cannot move; × 1.4826 is a standard deviation |
| **Manual integration** | a range integrated exactly as the operator marked it — [[peak-review]] |
| **MRM, MRM-HR** | multiple reaction monitoring: one precursor, one product, per transition; the high-resolution variant on a TripleTOF records the whole product spectrum |
| **mzML** | the open interchange format — [[formats]] |
| **Noise region** | the stretch of baseline the noise behind a signal-to-noise is measured over — [[signal-to-noise]] |
| **Peak-to-peak** | the full swing of a noise region, the stricter noise measure |
| **ppm** | parts per million: a relative mass window; 10 ppm at 500 is 5 mDa |
| **Precursor, fragment** | the ion isolated in Q1, and the product ion measured after fragmentation |
| **Profile** | a spectrum recorded as a continuous curve, as against centroids |
| **Qualifier, quantifier** | a second transition confirming the first; the first is what is quantified |
| **r²** | the coefficient of determination; 1 is an exact fit — and an exact fit through as many points as parameters means nothing |
| **RDBE** | ring-and-double-bond equivalents of a formula |
| **Response** | the number a component is reported by: area, ratio, or concentration |
| **RT window** | retention time ± half width: where the apex may be — [[integration-parameters]] |
| **S/N** | signal-to-noise: peak height over the noise — [[signal-to-noise]] |
| **Scheduled method** | a method that acquires each transition only around its expected time, in periods |
| **Spearman's ρ** | a rank correlation; how monotonic a change is |
| **Summation** | the area above a line across the whole window, no peak finding — [[integration-algorithms]] |
| **Survey scan** | the full-scan (TOF MS) experiment that sees everything eluting |
| **TIC** | total ion chromatogram: the sum of each scan against time |
| **TOF MS, TOF PI** | SCIEX's names for the survey scan and a product-ion scan on a TripleTOF |
| **Trapezoid** | the area between sampled points joined by straight lines — the valley algorithm's area |
| **Valley** | the low point between two peaks; the boundary the default algorithm walks to |
| **.wiff** | SCIEX's acquisition format — [[how-wiff-is-read]] |
| **XIC** | extracted ion chromatogram: one mass window against time — [[manual-xic]] |
