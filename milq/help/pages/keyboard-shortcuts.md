---
title: Keyboard shortcuts
---
On macOS, Ctrl is ⌘.

## Everywhere

| Shortcut | Action |
|---|---|
| Ctrl+N | New project… |
| Ctrl+O | Add data files… |
| Ctrl+S | Save project |
| Ctrl+Shift+S | Save project as… (in the Explorer, this toggles the Samples and channels dock instead) |
| Ctrl+1 / 2 / 3 / 4 | Explorer / Analytics / Method / Samples — see [[workspaces]] |
| F1 (⌘? on macOS) | this manual, on the page for the panel that has the focus |
| Ctrl+Q | Quit |

## Explorer

| Shortcut | Action |
|---|---|
| ← → | previous / next scan |
| Shift + drag on the chromatogram | select a range: average spectrum, integration in the status bar |
| Shift + drag on the spectrum | select an m/z range, for *Extract XIC from selection* |
| double-click a plot | fit |
| Delete, in the Active XICs list | remove the selected XIC |
| Ctrl+Shift+S | show or hide the Samples and channels dock |
| Ctrl+Shift+P | show or hide the side panels |
| Ctrl+Shift+1 … 9 | bring a side panel to the front, in the order of its tabs — see [[explorer]] |

## Analytics

| Shortcut | Action |
|---|---|
| Shift + drag on a panel | integrate exactly that range by hand — see [[peak-review]] |
| double-click a panel | magnify it; again to return |
| right-click a panel | set the noise region, or go back to automatic integration |
| click a point on the calibration plot | include or exclude that standard |
| double-click a row of the calibration table | the same |

## Manual window

| Shortcut | Action |
|---|---|
| Ctrl+F | the search box |
| Enter, in the search box | open the first hit |
| Alt+← / Alt+→ (⌘[ / ⌘] on macOS) | back / forward |
