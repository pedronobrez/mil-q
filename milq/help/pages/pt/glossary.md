---
title: Glossário
---
| Termo | Significado |
|---|---|
| **Aduto** | o íon em que uma molécula neutra se transforma na fonte: [M−H]⁻, [M+H]⁺, [M+Na]⁺… A [[mass-calculator]] lista os que são suportados |
| **Ápice** | o ponto mais alto de um pico; o seu tempo é o tempo de retenção reportado |
| **Razão de áreas** | a área de um componente dividida pela do seu padrão interno na mesma amostra |
| **Linha de base** | o sinal sob um pico que não é o pico; desenhada como uma reta entre os limites na integração, ou estimada como um envelope inferior pelo parâmetro *Baseline (min)* |
| **BPC** | cromatograma de pico base: o pico mais alto de cada scan contra o tempo |
| **Carryover (arraste)** | analito de uma injeção aparecendo na seguinte; medido no branco após o padrão mais alto — [[detection-limits-and-carryover]] |
| **Centroide** | um pico em perfil reduzido a um só bastão no seu centro de massa |
| **Componente** | um alvo do método: o que extrair, onde, e como reportá-lo — [[method-workspace]] |
| **Carta de controle** | a resposta de um padrão contra a ordem de injeção, com limites — [[batch-qc]] |
| **%CV** | coeficiente de variação: o desvio padrão como porcentagem da média |
| **Da, mDa** | dalton e milidalton; uma janela de massa absoluta |
| **Fator de diluição** | aquilo por que uma concentração lida da curva é multiplicada para reportar a amostra original |
| **Deriva** | uma mudança de resposta que vai num só sentido ao longo da corrida |
| **Ajuste gaussiano** | uma área de pico obtida de uma curva em sino ajustada aos pontos em vez do trapézio — [[integration-algorithms]] |
| **Índice de resposta da injeção** | a mediana, sobre os padrões internos, da resposta de cada um relativa à sua própria mediana, por injeção — [[batch-qc]] |
| **Padrão interno (IS)** | um composto adicionado a toda amostra em uma única quantidade, contra o qual os analitos são expressos em razão — [[internal-standards-and-qualifiers]] |
| **Razão iônica** | a área de um qualificador como porcentagem da do seu quantificador |
| **LM_ID** | um identificador de registro do LIPID MAPS, `LMSP03010003` — [[lipid-maps]] |
| **LOD, LOQ** | limites de detecção e de quantificação, 3.3σ/S e 10σ/S — [[detection-limits-and-carryover]] |
| **MAD** | desvio absoluto mediano: uma dispersão que um outlier não consegue mover; × 1.4826 é um desvio padrão |
| **Integração manual** | uma faixa integrada exatamente como o operador a marcou — [[peak-review]] |
| **MRM, MRM-HR** | monitoramento de reações múltiplas: um precursor, um produto, por transição; a variante de alta resolução em um TripleTOF registra o espectro de produtos inteiro |
| **mzML** | o formato aberto de intercâmbio — [[formats]] |
| **Região de ruído** | o trecho de linha de base sobre o qual se mede o ruído por trás de um sinal/ruído — [[signal-to-noise]] |
| **Pico a pico** | a excursão completa de uma região de ruído, a medida de ruído mais estrita |
| **ppm** | partes por milhão: uma janela de massa relativa; 10 ppm em 500 são 5 mDa |
| **Precursor, fragmento** | o íon isolado no Q1 e o íon produto medido após a fragmentação |
| **Perfil** | um espectro registrado como uma curva contínua, por oposição a centroides |
| **Qualificador, quantificador** | uma segunda transição que confirma a primeira; a primeira é a que é quantificada |
| **r²** | o coeficiente de determinação; 1 é um ajuste exato — e um ajuste exato através de tantos pontos quantos são os parâmetros não significa nada |
| **RDBE** | equivalentes de anéis e duplas ligações de uma fórmula |
| **Resposta** | o número pelo qual um componente é reportado: área, razão ou concentração |
| **Janela de RT** | tempo de retenção ± meia largura: onde o ápice pode estar — [[integration-parameters]] |
| **S/N** | sinal/ruído: a altura do pico sobre o ruído — [[signal-to-noise]] |
| **Método agendado** | um método que adquire cada transição apenas em torno do seu tempo esperado, em períodos |
| **ρ de Spearman** | uma correlação de postos; quão monotônica é uma mudança |
| **Somatório** | a área acima de uma reta ao longo de toda a janela, sem busca de picos — [[integration-algorithms]] |
| **Varredura de survey (survey scan)** | o experimento de varredura completa (TOF MS) que enxerga tudo o que elui |
| **TIC** | cromatograma de íons totais: a soma de cada scan contra o tempo |
| **TOF MS, TOF PI** | os nomes da SCIEX para a varredura de survey e uma varredura de íons produto em um TripleTOF |
| **Trapézio** | a área entre pontos amostrados unidos por retas — a área do algoritmo de vale |
| **Vale** | o ponto baixo entre dois picos; o limite até onde o algoritmo padrão caminha |
| **.wiff** | o formato de aquisição da SCIEX — [[how-wiff-is-read]] |
| **XIC** | cromatograma de íon extraído: uma janela de massa contra o tempo — [[manual-xic]] |
