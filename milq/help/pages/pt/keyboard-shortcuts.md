---
title: Atalhos de teclado
---
No macOS, Ctrl é ⌘.

## Em toda parte

| Atalho | Ação |
|---|---|
| Ctrl+N | New project… (novo projeto) |
| Ctrl+O | Add data files… (adicionar arquivos de dados) |
| Ctrl+S | Save project (salvar projeto) |
| Ctrl+Shift+S | Save project as… (salvar projeto como; no Explorer, alterna a doca Samples and channels em vez disso) |
| Ctrl+1 / 2 / 3 / 4 | Explorer / Analytics / Method / Samples — ver [[workspaces]] |
| F1 (⌘? no macOS) | este manual, na página do painel que está com o foco |
| Ctrl+Q | Quit (sair) |

## Explorer

| Atalho | Ação |
|---|---|
| ← → | scan anterior / seguinte |
| Shift + arrastar no cromatograma | selecionar uma faixa: espectro médio, integração na barra de estado |
| Shift + arrastar no espectro | selecionar uma faixa de m/z, para *Extract XIC from selection* |
| duplo clique em um gráfico | ajustar |
| Delete, na lista Active XICs | remover o XIC selecionado |
| Ctrl+Shift+S | mostrar ou ocultar a doca Samples and channels |
| Ctrl+Shift+P | mostrar ou ocultar os painéis laterais |
| Ctrl+Shift+1 … 9 | trazer um painel lateral para a frente, na ordem das suas abas — ver [[explorer]] |

## Analytics

| Atalho | Ação |
|---|---|
| Shift + arrastar em um painel | integrar exatamente aquela faixa à mão — ver [[peak-review]] |
| duplo clique em um painel | ampliá-lo; de novo para voltar |
| clique direito em um painel | definir a região de ruído, ou voltar à integração automática |
| clique em um ponto do gráfico de calibração | incluir ou excluir aquele padrão |
| duplo clique em uma linha da tabela de calibração | o mesmo |

## Janela do manual

| Atalho | Ação |
|---|---|
| Ctrl+F | a caixa de busca |
| Enter, na caixa de busca | abrir o primeiro resultado |
| Alt+← / Alt+→ (⌘[ / ⌘] no macOS) | voltar / avançar |
