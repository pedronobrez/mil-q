## The name

MIL stands for *Multi-omics Identification Laboratory*. MIL-X explores a
sample and MIL-Q quantifies one: explore, then quantify, with MIL-X writing
the component list MIL-Q reads. The two carry the same mark, a cow's head
face on, and MIL-Q's is inside a ring because a targeted assay is aimed at
something.

The rule is the one the OpenPeakView rename set in 0.6.1: **the old name
goes on being understood and is never written again.** Nothing has to be
moved by hand and nothing has to be set up twice.

| Was | Is | What happens to the old one |
|---|---|---|
| OpenQuant.app, OpenQuant.exe | MIL-Q.app, MIL-Q.exe | installing MIL-Q on Windows replaces an installed OpenQuant rather than leaving two |
| `~/.openquant` | `~/.milq` | a machine that has the old directory goes on using it — it holds a .NET runtime and a 45 MB index, and moving either would be work for nothing. A machine without one gets the new name |
| `OPENQUANT_*` | `MILQ_*` | each old name is read as its new twin at startup where the new one is not set. `OPENPEAKVIEW_HOME`, the name before last, is read as `MILQ_HOME`. Both are on their way out |
| preferences under *OpenQuant* | under *MIL-Q* | the first MIL-Q started on a machine copies what OpenQuant remembered — the window's size, the last folder, whether the start prompt was dismissed — and never copies again |
| `openquant` on the command line | `milq` | the Python package is `milq` as well: `import milq`, `python3 -m milq.app` |
| `.oqproj` | `.oqproj` | unchanged, read and written. `.opvproj`, older still, is read |
| `github.com/pedronobrez/openquant` | `github.com/pedronobrez/mil-q` | the old address redirects |

The macOS bundle ships without the layered *Liquid Glass* icon this
version — see [[installation]].

## Not yet in a released version

A manual read from the source tree describes what the source tree does,
which runs ahead of the last tag between releases; work on the main branch
that has not been in a release is listed here, and named in the row of the
version that ships it. There is nothing at the moment: these pages describe
what 0.10.0 does.

The manual is part of every release: a version that changes what the
application does changes the page that describes it, and the printed copy
is regenerated from the same pages.
